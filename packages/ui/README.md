# @arbyte/ui

کامپوننت‌های مشترک بین `apps/web` و `apps/admin` (بند ۱۲.۱۷ — Component Architecture).

این پکیج فعلاً خالی است. کامپوننت‌های پایه (Button, Input, Select, Modal, Card, Badge, Table,
Tabs, Dropdown, Toast) در **T-002 — Core Components** ساخته می‌شوند، روی توکن‌های `packages/tokens`.

هیچ کامپوننتی نباید رنگ HEX یا رشته‌ی فارسی hardcode داشته باشد — قانون ESLint در
`packages/config` این را در Build اجرا می‌کند.
