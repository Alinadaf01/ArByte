# چک‌لیست لانچ آربایت

پایه: برندبوک بند ۱۲.۷۰ (Final Launch Checklist) و ۱۲.۷۱ (هیچ جریان حیاتی بدون اجرای واقعی «کامل» نیست)، به‌علاوه‌ی موارد G-04. هر ردیف ستون «چطور بررسی شود» دارد. تیک بزنید و تاریخ بگذارید.

## ۰. زیرساخت

| ✓   | مورد                                                                          | چطور بررسی شود                                                                                                                   |

| ☐   | `check --deploy` تمیز                                                         | `docker compose … exec web python manage.py check --deploy` → «no issues»                                                        |
| ☐   | secretها تصادفی و بیرون از git؛ `FIELD_ENCRYPTION_KEY` جایی امن بیرون از سرور | `ls -l .env.production` → `-rw-------`؛ `git status` آن را نشان ندهد                                                             |

| ☐   | زمان پاسخ Vercel ↔ ایران                                                      | `scripts/measure-latency.sh https://arbyte.ir https://api.arbyte.ir` → TTFB < ۸۰۰ms (DEPLOY §۴.۳)                                |
