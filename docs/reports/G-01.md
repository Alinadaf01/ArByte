# G-01 — صفحه‌های محتوایی

وضعیت: ✅ کامل

## بک‌اند

- **API عمومی** (`public_api/content_views.py`): `blog` (دسته، جستجو، صفحه‌بندی)، `blog/categories`، `blog/:slug` (sanitize سمت سرور با **nh3**؛ متن ساده → پاراگراف، `> ` → نقل‌قول)، `content/about`، `content/legal`، `content/site-info`، `POST contact` (نرخ ۵/ساعت)، `catalog/products/:slug/reviews` (GET/POST).
- **مدل‌ها** (migration `content.0009`): `AboutPage` (singleton)، `LegalDocument` (terms/privacy/shipping/returns/warranty)، `ContactMessage.order_number` و ایمیل اختیاری، یکتایی نظر (محصول، کاربر)، دسته‌های وبلاگ طبق طراحی.
- **پنل**: صفحه‌ی «صفحه‌های محتوا» (درباره ما + اسناد قوانین) با لاگ فعالیت؛ راهنمای قالب متن در فرم بلاگ. ذخیره‌ی بلاگ/درباره ما/قوانین/نظر → revalidate صفحه‌های فروشگاه.
- **قرارداد**: `content/pages.ts` (Zod) + `rating` در جزئیات محصول؛ `contract:test` ۶۰/۶۰ (۶ تست تازه).

## فروشگاه

- `/blog`: نوشته‌ی ویژه، چیپ دسته، جستجو، کارت‌ها، صفحه‌بندی؛ فیلترشده `noindex`. فرم خبرنامه پنهان.
- `/blog/[slug]`: نوار پیشرفت ۳px، فهرست مطالب (≥۲ بخش)، نقل‌قول/تصویر/لینک امن، کپی لینک، برچسب‌ها، نویسنده، «ادامه بدهید»؛ JSON-LD `Article` + `BreadcrumbList`، OG/Twitter، canonical. دکمه‌ی «ذخیره» پنهان.
- مجله‌ی صفحه اصلی از API (قوس با تعداد واقعی، <۳ نوشته = پنهان)؛ داده‌ی نمونه‌ی `home-journal.ts` و `BlogRailSection` بی‌مصرف حذف شد. تب «نوشته‌ها»ی `/search` برگشت.
- `/about`: متن از پنل، بخش خالی پنهان، آمار از `storeFacts`؛ متن نمونه‌ی طراحی (سال/تیم/آمار ساختگی) از قرارداد حذف شد.
- `/support`: فرم واقعی → `POST /contact` → پنل «پیام‌ها» با کد پیگیری روی صفحه؛ کانال تلفن فقط با شماره‌ی SiteSettings؛ حضوری/نقشه/«آنلاین» پنهان؛ ساعات از SiteSettings یا `storeFacts`.
- `/legal`: FAQ مشترک + اسناد از پنل؛ **هیچ متن حقوقی در کد نمانده**.
- ۴۰۴: جستجو حالا فرم واقعی است (Enter کار می‌کند).
- نظرات محصول زیر تب‌ها: فهرست تأییدشده‌ها، پاسخ ادمین، فرم فقط برای خریدار DELIVERED؛ AggregateRating فقط با ≥۳ نظر (Q-42).
- هدر/فوتر: تلفن، ایمیل، نشانی، شبکه‌های اجتماعی و نماد اعتماد از SiteSettings؛ خالی = پنهان (قبلاً شماره/نشانی نمونه و لینک `#` بود).
