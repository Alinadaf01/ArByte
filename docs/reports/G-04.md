# G-04 — استقرار: سرور ایران + Vercel، بک‌آپ، چک‌لیست لانچ

وضعیت: ✅ کامل (به‌جز اندازه‌گیری تأخیر واقعی Vercel ↔ ایران — Q-46)

## فایل‌ها

- `docker-compose.prod.yml`: db، redis، web (gunicorn، healthcheck)، celery-worker، celery-beat، nginx (پنل ایستا + پراکسی)، certbot (profile tools). volumeهای نام‌دار `arbyte_*`؛ Postgres/Redis بدون پورت بیرونی. رسیدها در volume جدای `private_media` که nginx به آن دسترسی ندارد.
- `deploy/nginx/`: ایمیج nginx با build پنل داخلش؛ `api.*` و `admin.*`، HSTS/CSP، حالت `bootstrap` برای گرفتن اولین گواهی.
- `deploy/setup.sh` (مراحل ۱ تا ۷: سخت‌سازی، Docker، env با secret تصادفی، ایمیج‌ها، سرویس‌ها + SSL، cron، smoke).
- `deploy/deploy.sh <tag>`: pull (یا `docker load` از `deploy/incoming/`) → migrate → جایگزینی چرخشی web بدون قطعی → rollback خودکار اگر health قرمز شد.
- `deploy/backup.sh` / `deploy/restore.sh`: pg_dump + media + private_media + SHA256SUMS، نگه‌داری ۱۴ روز، کپی اختیاری به S3.
- `.env.production.example`: همه‌ی کلیدها با توضیح؛ شماره‌های اعلان و کارت‌به‌کارت در پنل‌اند (یادآوری در فایل).
- `.github/workflows/build-images.yml` + job `images` در CI (build بدون push روی PR).
- `scripts/smoke.sh`، `scripts/measure-latency.sh`.
- `docs/DEPLOY.md` (فارسی، قدم‌به‌قدم: DNS، سرور، Vercel، به‌روزرسانی، بک‌آپ، عیب‌یابی)، `docs/LAUNCH-CHECKLIST.md`.
- کاوه‌نگار: `KAVENEGAR_API_KEY` از env به‌عنوان جایگزین (کلید پنل اولویت دارد).
- `manage.py payment_sandbox_check <gateway>`: آزمون درگاه در حالت sandbox بدون تغییر تنظیمات.

## آزمون (محلی، Docker واقعی)

- هر دو ایمیج ساخته شدند؛ کل استک با `NGINX_MODE=ssl` و گواهی self-signed بالا آمد، همه‌ی سرویس‌ها healthy.
- `scripts/smoke.sh` همه سبز (health، API، پنل، هدرهای امنیتی، ۴۰۴ رسید، فید ترب).
- ورود به پنل از پشت nginx با CSP کار کرد.
- `deploy.sh` چرخشی: صفر خطای web در حین جایگزینی (فقط ~۰٫۴ ثانیه هنگام recreate خود nginx).
- بک‌آپ → حذف داده و فایل → restore → هر دو برگشتند.
- تست‌های Django تازه (کلید env کاوه‌نگار، sandbox) سبز.
