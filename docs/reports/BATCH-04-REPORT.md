## کیفیت

- Django ۴۱۱ تست سبز، ۰ skip؛ ruff تمیز؛ migration معلق ندارد.
- `typecheck` ۵/۵، `lint` ۰ خطا، web ۱۰۰، contracts ۸۵، ui ۵۲، `contract:test` ۵۴/۵۴ روی Django زنده.
- مرورگر ۱۴۴۰ و ۳۷۵ برای همه‌ی صفحه‌های پنل: بدون خطای کنسول، بدون ۵xx، بدون اسکرول افقی.
- هر عمل ادمین در `AdminActivityLog` ثبت می‌شود؛ مبالغ BigInteger تومان؛ همه‌ی تاریخ‌ها و فیلترهای تاریخ شمسی.
- قرارداد عمومی دست نخورد. فروشگاه فقط جاهایی که تسک خواسته بود تغییر کرد: `/api/revalidate` و rewrite `/media` در F-02، و `/impersonate` و نوار هشدار در F-04.

## باگ‌های مهمِ پیداشده و رفع‌شده

- گرد کردن float در قیمت (۱۲٬۰۰۰٬۰۰۰×۱٫۱ → ۱۳٬۲۰۱٬۰۰۰): موتور قیمت و قیمت انبوه با حساب صحیح.
- parser camelCase کلیدهای داخل JSON (config صفحه اصلی، نگاشت اکسل) را عوض می‌کرد: نرمال‌سازی کلید و قالب جفت `{field, header}`.
- گزارش ماهانه روی ماه میلادی گروه می‌شد: حالا ماه شمسی.

## برای بچ بعد

- اتصال واقعی سرچ کنسول (بچ ۰۵)؛ صفحه‌اش آماده است.

- کلید کاوه‌نگار از پنل تنظیم می‌شود، نه env: تنظیمات ← کلیدهای API ← کاوه‌نگار.
