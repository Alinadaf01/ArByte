# F-04 — کاربران، نقش‌ها، فروش، محتوا، گزارش‌ها + پاک‌سازی

وضعیت: ✅ کامل

## صفحه‌ها

- **کاربران:** فهرست/جستجو، ساخت، غیرفعال‌سازی، ریست رمز، خروج اجباری، صورت‌حساب PDF. **Impersonation** (فقط superuser): بلیت ۶۰ ثانیه‌ای یک‌بارمصرف → `apps/web/src/app/impersonate` در BFF تبادل می‌شود → نوار زرد دائمی «در حال مشاهده به‌جای … · توسط …» با دکمه‌ی خروج (`ImpersonationBanner`). عملیات ممنوع سمت سرور ۴۰۳ `IMPERSONATION_FORBIDDEN_ACTION`؛ استفاده‌ی دوباره از بلیت → `/login?impersonation=failed` (Q-40).
- **نقش‌ها:** CRUD مجوزهای بخشی (موجود از قبل، تأیید شد).
- **کوپن‌ها:** CRUD کامل (درصدی/مبلغی، سقف، حداقل سفارش، محدودیت کل و هر کاربر، بازه) + آمار: دفعات، کاربران یکتا، جمع تخفیف.
- **مرجوعی‌ها:** تصمیم قلم‌به‌قلم (`ReturnItem.decision`، migration `orders.0008`)؛ «دریافت کالا» فقط قلم‌های تأییدشده را `STOCK_IN` می‌کند (Q-38).
- **نظرات:** تأیید/رد + پاسخ ادمین. **پیام‌ها:** خواندن + یادداشت.
- **بلاگ:** CRUD، کاور با **alt اجباری** (`BlogPost.cover_alt`، migration `content.0008`)، زمان مطالعه خودکار، پیش‌نویس/منتشر، SEO.
- **گزارش‌ها:** فروش روزانه/هفتگی/ماهانه با برچسب شمسی — ماهانه روی **ماه شمسی** (Q-39)؛ پرفروش‌ترین‌ها؛ **روش پرداخت از snapshot `Payment`** (کارت‌به‌کارت / نام درگاه)؛ خروجی Excel.
- **لاگ فعالیت:** فیلتر کاربر/عمل/تاریخ. **سرچ کنسول:** صفحه می‌ماند، تا اتصال (بچ ۰۵) حالت «داده‌ای نیست» از `search-console/status/`.
- **تاریخ شمسی:** `JalaliDateInput` (روز/ماه/سال) جای همه‌ی `input[type=date]` میلادی پنل (سفارش‌ها، کاردکس، گزارش‌ها، لاگ، سرچ کنسول)؛ API همان ISO.
