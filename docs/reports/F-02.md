# F-02 — کاتالوگ در پنل ادمین (روی مدل واریانت)

وضعیت: ✅ کامل

## بک‌اند

- پنج فایل خاموش (`products`، `pricing`، `specs`، `inventory`، `homepage`) روی `ProductVariant`/`Inventory`/`SpecificationDefinition`/`HomepageBlock` **از نو نوشته و وصل** شدند؛ `docs/backend/ADMIN-DISABLED.md` حذف شد. همه‌ی ۵۲ تست `@skip` یا بازنویسی و فعال شدند یا (کد وایبِ HeroSection/Showcase/CommunityTile/ColorOption) با خود کد رفتند — **skip صفر**. مسیرها در `docs/api/ADMIN.md`.
- برند CRUD (حذف برند دارای محصول → ۴۰۰)؛ دسته با سه تصویر، حذف‌شده‌ها پنهان.
- `POST uploads/`: هر تصویر سمت سرور WebP (حداکثر ۲۴۰۰px، ۸MB). تصاویر محصول: آپلود چندتایی با alt اجباری، ترتیب، تصویر اصلی.
- ویرایشگر واریانت: `PUT products/:id/variants/` کل جدول — اعتبارسنجی یک پیش‌فرض، SKU یکتا، ترکیب محور یکتا، قیمت مثبت؛ موجودی با `Inventory.adjust` (کاردکس)، تغییر قیمت در `PriceHistory`؛ ردیف حذف‌شده‌ی دارای سفارش → حذف نرم. برچسب را سرور می‌سازد (`build_variant_label` فروشگاه، مسیر preview). قیمت همکار/سود فقط با مجوز `cost_price`.
- مشخصات: CRUD تعریف/مقدار (`swatchHex`)؛ محور فقط SELECT/COLOR؛ مشخصات سطح محصول با فیلدهای اجباری.
- موجودی: موجود/رزرو/قابل فروش/آستانه، تراکنش دستی با دلیل (رزرو/آزادسازی فقط سیستمی)، کاردکس + Excel/PDF، برگه‌ی انبارگردانی و لیست قیمت PDF دوباره وصل شدند.
- قیمت انبوه: preview و apply **یک تابع مشترک**؛ گرد به ۱۰۰۰ تومان بالا.
- صفحه اصلی: اعتبارسنجی config هر نوع طبق `block-config.ts` (slug/مشخصه‌ی واقعی). **باگ پیدا و رفع شد:** `CamelCaseJSONParser` کلیدهای داخل `config` را snake می‌کرد (`productSlugs`→`product_slugs`) و فروشگاه آن را نمی‌خواند؛ حالا به شکل اصلی برمی‌گردند.
- سئو: مدل `SeoMetadata` (Q-34)؛ `seo` در API عمومی محصول حالا واقعی است.
- کش فروشگاه: بعد از ذخیره‌ی محصول/قیمت/صفحه اصلی، Django (`STOREFRONT_URL` + `REVALIDATE_SECRET`) مسیر `POST /api/revalidate` فروشگاه را صدا می‌زند (جدید در `apps/web`، `revalidatePath`، بدون secret → ۴۰۱). بدون env هیچ کاری نمی‌کند و کش ۳۰–۶۰ ثانیه‌ای قبلی می‌ماند.
- فروشگاه: rewrite ‏`/media/*` → بک‌اند تا تصاویر آپلودی پنل هم‌مبدأ باشند.

## فرانت پنل

محصولات (فیلتر دسته/برند/وضعیت/شرایط/موجودی، جستجوی نام/SKU)، فرم محصول (اطلاعات، گارانتی، سئو، «مشاهده در سایت»)، تصاویر (کشیدن برای ترتیب)، مشخصات، ویرایشگر واریانت (محور → مقادیر → «ساخت ترکیب‌ها» → جدول)، برندها (جدید در منو)، دسته‌ها، مشخصات، موجودی، کاردکس، اصلاح قیمت (پیش‌نمایش قبل از اعمال، تاریخچه)، صفحه اصلی (ترتیب، فعال، زمان‌بندی، فرم هر نوع). هیچ «به‌زودی» نماند.

## تست و تأیید

- Django: همه سبز، **۰ skip**؛ ۱۸ تست جدید کاتالوگ + ۴ تست سند فعال‌شده؛ سفر پنل → API عمومی (محصول ۳ واریانتی، فیلتر `spec[…]`، برچسب، قیمت، سئو).
- `typecheck` ۵/۵، `lint` ۰ خطا، web ‏۱۰۰/۱۰۰، `contract:test` ۵۴/۵۴.
- مرورگر: محصول ۳ واریانتی کامل از رابط پنل ساخته شد (محور، ترکیب، قیمت، موجودی، تصویر) → فروشگاه `/products/legion-5-f02?v=53` واریانت «32GB · 1TB» با ۷۰٬۰۰۰٬۰۰۰ و «۱ عدد موجود»، تصویر WebP و عنوان سئو؛ صفحه‌ی دسته محصول را نشان داد. ویرایش عنوان دوئل پرچم‌دار از API پنل → API صفحه اصلی عوض شد؛ `/api/revalidate` با secret ۲۰۰. صفحه‌های پنل در ۱۴۴۰ و ۳۷۵ بدون خطای کنسول.
