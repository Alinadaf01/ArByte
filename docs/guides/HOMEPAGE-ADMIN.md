# راهنمای تنظیم صفحه‌ی اصلی از پنل

همه‌ی بخش‌های صفحه‌ی اصلی از پنل ادمین تنظیم می‌شوند. بعد از ذخیره، فروشگاه حداکثر چند دقیقه بعد به‌روز می‌شود.

## ترتیب بخش‌ها در سایت

ترتیب نمایش در سایت ثابت است و از طراحی می‌آید، نه از ترتیب ردیف‌ها در پنل:

1. هیرو
2. دسته‌ها
3. دوئل پرچم‌دار
4. محصولات منتخب
5. مجله (بلاگ)
6. سوالات متداول
7. جامعه
8. مزایا

از هر نوع بلوک فقط **اولین بلوک فعال** نمایش داده می‌شود. بلوکی که پیدا نشود یا داده‌ی معتبر نداشته باشد، بی‌صدا پنهان می‌شود و صفحه خراب نمی‌شود.

## پنل → «صفحه اصلی» (بلوک‌ها)

دکمه‌ی «بلوک جدید» یا ویرایش بلوک موجود. فیلدهای مشترک همه‌ی بلوک‌ها:

- **نوع بلوک**
- **عنوان / زیرعنوان**: متن بالای بخش.
- **دکمه (متن / لینک)**
- **شروع نمایش / پایان نمایش**: خالی یعنی «از الان» و «بدون پایان». بلوک فقط در این بازه دیده می‌شود.
- **تصویر دسکتاپ / موبایل / متن جایگزین**
- **فعال**

تنظیمات اختصاصی هر نوع:

| نوع بلوک                           | چه چیزی تنظیم می‌شود                            | نکته                                                                                                                                            |
| ---------------------------------- | ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **هیرو**                           | مسیر manifest                                   | مقدار پیش‌فرض: `/hero/manifest.json`. ویدیو و پوستر هیرو همراه کد deploy می‌شوند.                                                               |
| **شبکه‌ی دسته‌ها**                 | حداکثر ۵ دسته                                   | هر دسته در پنل «دسته‌ها» باید تصویر داشته باشد، وگرنه کاشی بی‌تصویر می‌ماند.                                                                    |
| **دوئل پرچم‌دار**                  | دو محصول و دو مشخصه‌ی مقایسه (مثلاً رم و حافظه) | هر دو محصول باید فعال و نمایش‌داده‌شده در سایت باشند، وگرنه کل بخش پنهان می‌شود. مقدار مشخصه از خود محصول یا پیکربندی پیش‌فرض آن خوانده می‌شود. |
| **ردیف محصولات** («محصولات منتخب») | فهرست محصولات، با جستجو اضافه می‌شوند           | **اولین محصول کارت بزرگ است و بقیه کارت کوچک.** برای چیدمان کامل **۴ محصول** بگذارید (۱ بزرگ + ۳ کوچک). ترتیب افزودن همان ترتیب نمایش است.      |
| **مزایا**                          | تنظیم اختصاصی ندارد                             | فقط فعال بودن و عنوان.                                                                                                                          |

### چرا محصولات صفحه‌ی اصلی نمایش داده نمی‌شوند؟

همه‌ی موارد زیر را به ترتیب بررسی کنید:

1. یک بلوک از نوع **«ردیف محصولات»** وجود دارد و **فعال** است.
2. بازه‌ی «شروع/پایان نمایش» آن شامل امروز است.
3. محصولات به آن اضافه شده‌اند. اگر فهرست خالی باشد، بخش نمایش داده نمی‌شود.
4. هر محصول در پنل «محصولات» این شرایط را دارد:
   - وضعیت **فعال** است.
   - **«نمایش در سایت»** روشن است.
   - **حداقل یک پیکربندی (واریانت) حذف‌نشده** دارد.

   محصولی که یکی از این شرایط را نداشته باشد، از ردیف حذف می‌شود.

5. روی سرور این دستور را بزنید تا وضعیت همه‌ی بخش‌ها گزارش شود. این دستور فقط می‌خواند و چیزی را تغییر نمی‌دهد:

   ```
   python manage.py check_homepage_data
   ```

## بخش‌هایی که خارج از «صفحه اصلی» تنظیم می‌شوند

| بخش سایت               | کجای پنل                                                                                                                                                                                                                                                                    |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **مجله**               | «بلاگ»: نوشته‌های منتشرشده، تا ۹ مورد آخر.                                                                                                                                                                                                                                  |
| **سوالات متداول**      | «صفحه‌های محتوا» → تب **«سوالات متداول»**: افزودن، ویرایش، حذف و جابه‌جایی. با تیک **«نمایش در صفحه‌ی اصلی»**، چهار سوال اولِ تیک‌خورده در صفحه‌ی اصلی می‌آیند. همین فهرست در «قوانین و سوالات»، پشتیبانی و جستجو هم نمایش داده می‌شود.                                     |
| **ساعت پاسخ‌گویی**     | «تنظیمات» → «اطلاعات سایت» → **«ساعات کاری»**. ستون روز را مثل «شنبه تا پنجشنبه» و ستون ساعت را مثل «۹:۳۰ تا ۱۸:۰۰» بنویسید. نشان «آنلاین» صفحه‌ی اصلی، متن بالای صفحه‌ی پشتیبانی و منوی موبایل از همین‌جا خوانده می‌شوند. چند ردیف هم مجاز است؛ مثلاً پنجشنبه با ساعت جدا. |
| **تلفن تماس**          | «تنظیمات» → «اطلاعات سایت» → «تماس». دکمه‌ی «تماس تلفنی» فقط وقتی شماره ثبت شده باشد نمایش داده می‌شود.                                                                                                                                                                     |
| **جامعه**              | «تنظیمات» → «اطلاعات سایت» → «شبکه‌های اجتماعی».                                                                                                                                                                                                                            |
| **قوانین / درباره ما** | «صفحه‌های محتوا» → تب‌های «قوانین و اسناد» و «درباره ما».                                                                                                                                                                                                                   |
